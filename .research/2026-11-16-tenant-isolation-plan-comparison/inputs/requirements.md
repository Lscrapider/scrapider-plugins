# 租户读写隔离执行计划考题

题目用途是写计划和静态复演。选平台隔离的首批切片：数据批次及上传、流水线任务及输入绑定/运行，以及这两者的仪表盘统计。以下是三路共用的设计决定。A、B、平台空间是虚拟租户，开发交接可按设计开始。

| 要求 | 目标行为 |
| --- | --- |
| R1 可信身份 | 业务读写同时满足既有功能权限和真实租户。服务端用已认证 userId 按现有账号链路确认有效租户。客户端不得选租户。缺失或失效按现有拒绝方式处理。明确有效的 tenantId=0 是独立平台业务空间，父子租户业务数据相互隔离，平台管理权限沿用现状。保留现有个人和状态限制。 |
| R2 数据批次 | 列表、详情、计数、按名称检查、批次上传轮次与子文件都按批次归属。分页和统计前过滤。新批次服务端绑定租户，更新不可转移，名称在租户内唯一。外租户 ID 与不存在按同一已有错误路径处理。 |
| R3 上传和文件 | 分片初始化、part/status/merge/cancel、ZIP 结果、校验、预览/下载/删除在返回访问能力、写行、改状态或操作对象存储之前核对真实父批次与 ID 关系。同 MD5 不跨租户复用新引用或暴露命中，历史物理共享保留全局引用保护。 |
| R4 流水线与异步 | 任务的创建、列表/详情、绑定、运行/重试与可见阶段/执行记录按任务归属。A 的任务绑定混入 B 的批次须整体拒绝且无消息。异步 Java 入口用现有可信消息通道和持久化父记录恢复归属，核验关联 ID/版本，保留正常重试、幂等和既有协议。仪表盘只汇总本租户的批次和任务。 |
| R5 迁移与启用 | 允许先增加兼容结构。用可证明的创建时归属或可信父关系处理存量，无法证实或关系冲突的记录单列，禁止默认归平台。试验允许停写和排空。旧写入方未停止或归属冲突未处理时先安排可做工作，独立标注启用条件。给出初始化、存量升级及切换失败后的隔离边界。 |

**范围固定**：复用现有 Spring Boot、MyBatis、存储和消息设施。其它独立域、数据源/公共目录管理、Worker 协议升级和 UI 不是独立改造题。触达本题受保护对象的真实旁路应纳入交接或明确对首批启用的影响。保留现有 HTTP 形状、状态机、个人限制和运行默认值。

**验收**：用同权限 A/B、A 中有权限的伙伴以及平台/父子租户做对照，覆盖列表/详情、独立名称、上传 ID/文件 ID 错配、拒绝后无数据库/消息/存储副作用、合法与跨租户混合绑定、异步父子错配与正常重复投递、未归属数据和旧写入仍活动的切换。用具体输入、位置、结果和证据说明怎样验证。离线回归和开发可先执行，真实租户 HTTP/消息/对象存储验收用未来获准的非生产 fixture，缺环境只影响该项证据。

依据[共同源码事实](source-evidence.md)和原仓制定执行计划。遵守副本 AGENTS。现阶段只产出计划，禁止新增单元测试、依赖、Git 提交/分支/worktree 和启动服务。可复用既有测试，最后统一功能和规范审查。
